## 🎮 About

**Cola Battlegrounds** is a tactical cola-themed shooter inspired by the intensity of *CS:GO* and the ability-driven combat of *Valorant* — except every weapon, power-up, and battlefield is drenched in carbonated chaos.

Choose your side. Grab your can. The cola wars just went live.

## 🕹️ How to Play

1. **Download** the latest release for your OS
2. **Extract** the zip to any folder
3. **Launch** the executable
4. **Start / enter a room**, grab your gear, and start battling
5. **Collect power-ups** scattered across the map for the upper hand

### Default Controls

| Action | Key |
|--------|-----|
| Move | `W` `A` `S` `D` |
| Shoot | `Left Click` |
| Reload | `R` |
| Pause / Exit | `Esc` |

*Controls may vary — check in-game settings.*
